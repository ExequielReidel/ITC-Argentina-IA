Ejercicio 1 · 20 min

Mapeo avanzado de variables

Tomá el escenario de la Práctica 16 y mejorá el mail que se envía. Ahora queremos: el asunto debe incluir la fecha (hoy) y el cuerpo debe formatear los campos de manera prolija con HTML.

Cosas a probar:

  • En el asunto, usar la función formatDate(now; "DD/MM/YYYY")
  • En el cuerpo, marcar la opción "Content type: HTML" y usar <b>, <br> para formatear
  • Si el campo "Mensaje" está vacío, mostrar "Sin mensaje"
Tocá para ver pista

En Make, cuando hacés clic en un campo, abre un panel a la derecha con tabs: "Functions", "Date and time", "General", "Math", etc. Para condicional usá ifempty(variable; "Sin mensaje"). Para fechas, todas las funciones empiezan con format.

Listo si: tu mail llega con asunto que incluye la fecha y cuerpo con formato HTML.

Ejercicio 2 · 25 min

Programación temporal

Vas a armar un escenario que se ejecute todos los días a las 8:00 AM y te mande un mail con un "buen día" personalizado. Esto te enseña 2 cosas: cómo programar horarios y cómo crear escenarios sin trigger de aplicación.

Pasos:

  1. Nuevo escenario. En el primer módulo elegí Tools → "Set Variable" (o usá Gmail directo).
  2. En la configuración del escenario (abajo izquierda, ícono reloj), cambiá Scheduling de "On Demand" a "Every day at 08:00".
  3. Agregá módulo Gmail "Send Email" con un mensaje motivador para vos.
  4. Activá el escenario (switch ON).
Tocá para ver pista

Para probar sin esperar al día siguiente: cambiá temporalmente el horario a "5 minutos a partir de ahora" o ejecutá manual con "Run once". Importante: la zona horaria por defecto es UTC; configurá tu zona en Settings → Timezone → America/Buenos_Aires.

Listo si: tu escenario está programado para correr automáticamente cada día.

Ejercicio 3 · 25 min

Tu primer módulo HTTP

Vas a hacer una llamada a una API gratuita pública para traer un chiste random y enviártelo por mail. Esto te abre la puerta a conectar con CUALQUIER API.

Pasos:

  1. Nuevo escenario.
  2. Primer módulo: HTTP → Make a request.
  3. URL: https://official-joke-api.appspot.com/random_joke
  4. Method: GET
  5. Activá: Parse response (importante).
  6. Ejecutá "Run once". Vas a ver que devuelve un JSON con campos: setup, punchline, type.
  7. Agregá módulo Gmail. En el cuerpo del mail mapeá los campos setup y punchline.
Tocá para ver pista

Si Parse Response no está marcado, el resultado viene como texto plano y no podés mapear los campos. Es un error súper común. Si pasa: editá el módulo HTTP, activalo, y volvé a ejecutar Run once.

El chiste viene en inglés. Si querés, sumá un módulo entre HTTP y Gmail con OpenAI/ChatGPT que traduzca al argentino. Pero eso lo vamos a ver mejor en la Práctica 20.

Listo si: recibís un mail con un chiste real obtenido de una API pública.

Cierre

Antes de irte

  • ¿Qué tarea repetitiva tuya podría correr cada día sola?
  • ¿Qué API te gustaría conectar (clima, dólar, redes)?

Idea: el módulo HTTP es la "llave maestra". Cuando entendés cómo se usa, podés conectar con casi todo Internet.

Nota Docente — Solo para el profesor

El módulo HTTP es la primera vez que muchos alumnos van a "tocar" el concepto de API. No abrumar con teoría: hacer y mostrar. Si alguien se traba con "Parse response" no encontrado, recordales activar la opción dentro del módulo HTTP.
