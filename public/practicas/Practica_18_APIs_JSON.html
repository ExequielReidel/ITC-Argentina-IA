3 conceptos clave

API

Una "puerta" para que tu programa hable con otro. Vos pedís, te devuelve datos.

JSON

El formato más común de respuesta de una API. Es texto estructurado en clave-valor.

Endpoint

La URL específica de la API que te devuelve los datos que querés. Ej: /clima/hoy

Ejercicio 1 · 20 min

Dólar Argentina

Vamos a usar dolarapi.com, una API gratuita que devuelve el valor del dólar en Argentina (oficial, blue, MEP, etc.).

Pasos:

  1. Abrí https://dolarapi.com/v1/dolares en el navegador. Mirá la estructura del JSON que devuelve.
  2. En Make: nuevo escenario → módulo HTTP → Make a request.
  3. URL: https://dolarapi.com/v1/dolares/blue (este endpoint trae solo el dólar blue).
  4. Method: GET. Activá Parse response.
  5. Run once. Vas a ver campos: nombre, compra, venta, fechaActualizacion.
  6. Sumá Gmail y armá un mail con: "Hoy el dólar blue está a $[venta]. Última actualización: [fechaActualizacion]".
Tocá para ver pista

Otros endpoints útiles:

  • /v1/dolares/oficial
  • /v1/dolares/mep
  • /v1/dolares/tarjeta

Para que la fecha se vea linda, podés usar formatDate(fechaActualizacion; "DD/MM/YYYY HH:mm") en el cuerpo del mail.

Listo si: recibís un mail con el dólar blue actualizado del día.

Ejercicio 2 · 25 min

Clima de Buenos Aires

Vamos a usar open-meteo.com, otra API gratuita y sin token. Te devuelve el clima en cualquier punto del planeta.

Pasos:

  1. Coordenadas Buenos Aires: lat: -34.61, lon: -58.38.
  2. Endpoint: https://api.open-meteo.com/v1/forecast?latitude=-34.61&longitude=-58.38¤t=temperature_2m,weather_code&timezone=America/Buenos_Aires
  3. Pegalo en un navegador y mirá el JSON.
  4. En Make: nuevo escenario, módulo HTTP, GET, Parse response, esa URL.
  5. Buscá el campo current.temperature_2m.
  6. Mandate un mail: "En Buenos Aires hace [temperature_2m]°C ahora mismo".
Tocá para ver pista

Si querés tu ciudad, buscá las coordenadas en Google Maps:

  1. Andá a Google Maps
  2. Buscá tu ciudad
  3. Click derecho en el punto → primer número que aparece son las coordenadas

Bonus: agregale &daily=temperature_2m_max,temperature_2m_min para que te traiga máxima y mínima del día.

Listo si: recibís un mail con la temperatura actual de Buenos Aires (o tu ciudad).

Ejercicio 3 · 25 min

Tu Noticiero Personal

Combiná los Ejercicios 1 y 2: armá un único escenario que se ejecute cada mañana a las 8:00 AM y te mande un mail con dólar blue + clima del día. Como un noticiero pero solo con la info que a vos te importa.

Estructura sugerida:

[Schedule 8:00 AM] → [HTTP Dólar] → [HTTP Clima] → [Gmail con todo]

El mail debería tener algo así:

Asunto: ☀️ Tu briefing del [fecha]

Hola, este es tu briefing diario:

💵 Dólar Blue: $[venta]
🌤️ Buenos Aires: [temp]°C
📅 [fecha]

Que tengas un gran día.

Tocá para ver pista

Truco: en el módulo Gmail, en el campo "Body" podés alternar entre texto plano y HTML. Si elegís HTML, podés poner colores y emojis. Para conectar 2 módulos HTTP en serie: simplemente arrastrá el segundo después del primero. Make ejecuta en orden.

Listo si: tu escenario corre, te llega el mail combinando ambos datos, y está programado para las 8 AM diariamente.

Nota Docente — Solo para el profesor

Algunos alumnos van a confundirse con la estructura del JSON anidado (current.temperature_2m). Mostrales en pantalla cómo Make presenta los datos: cuando hacés clic en un campo del módulo siguiente, aparecen agrupados por nivel. Si un campo "no aparece" para mapear, es 99% por Parse Response apagado.
