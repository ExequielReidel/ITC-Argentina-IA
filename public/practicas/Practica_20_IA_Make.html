Repaso flash · 10 min

El concepto que cambia todo

Hasta acá, Make movía datos como una cinta transportadora: si pasa A, ejecuta B. Pero los datos del mundo real son desordenados. Un mail puede ser una consulta, un reclamo, una queja, un spam. La IA es lo que le da cerebro al flujo.

Antes

"Si llega un mail, mandalo a la planilla". Punto. Todos juntos. Después clasificás vos.

Ahora

"Si llega un mail, IA decide si es consulta/reclamo/spam y manda cada uno a un lado distinto".

Resultado

El bandeja deja de ser caótica. Los reclamos van a Telegram. Las consultas a la planilla. El spam, descartado.

Diseño del flujo de hoy:

Gmail · Watch OpenAI · Classify Router 3 acciones distintas

Ejercicio 1 · 20 min

La IA lee y clasifica

Vas a configurar Gmail (Watch Emails) + OpenAI (Create a Completion). Cuando llegue un mail, la IA devuelve una sola palabra: consulta, reclamo o spam.

1Módulo 1: Gmail

Trigger Watch Emails. Folder = INBOX, máximo 1 por ejecución mientras testeás. Si nunca usaste OAuth con Gmail, te pide login y permisos.

2Módulo 2: OpenAI · Create a Completion

Conectá tu cuenta OpenAI con tu API Key. Modelo: gpt-4o-mini (barato y rápido). Messages: 1 mensaje de tipo system + 1 de tipo user.

System message:

Sos un clasificador de mails de un negocio. Recibís el asunto y el cuerpo del mail. Tu única respuesta posible es UNA palabra de estas tres opciones, sin comillas ni puntuación: consulta, reclamo, spam. Si tenés dudas, elegí "consulta".

User message (con variables Make):

Asunto: {{1.Subject}}
Cuerpo: {{1.Text content}}

Tocá para ver pista si te trabás

• Si nunca creaste API Key de OpenAI: platform.openai.com/api-keys → Create new secret key. Tiene costo (centavos por uso).

• Para testear sin gastar: mandate vos un mail con asunto "Quiero consultar precios" y otro "Mi pedido nunca llegó, exijo reembolso". Comparalos.

• Importante: Max tokens = 10. No queremos que la IA escriba párrafos. Solo una palabra.

• Temperature = 0. Queremos respuesta determinística, no creatividad.

Listo si: el Run once muestra que el módulo OpenAI devolvió en su salida una de las tres palabras esperadas.

Ejercicio 2 · 25 min

Router con 3 ramas

Después del módulo OpenAI, agregá un Router. El router crea ramas paralelas; en cada rama vas a poner un filtro que solo deja pasar el caso correspondiente.

Tocá para ver cómo configurar los filtros

1. Después del módulo OpenAI, hacé clic con botón derecho → Add a router.

2. Sale 1 ruta. Hacé clic en el "+" para agregar más rutas. Total: 3 rutas.

3. En cada conexión hacia el módulo siguiente, hacé clic en la llave inglesa de la línea → "Set up a filter".

4. Configurá los 3 filtros así:

Rama 1 — Consultas:

Label: "Es consulta" — Condition: {{2.choices[].message.content}} · Text operator · contains · consulta

Rama 2 — Reclamos:

Label: "Es reclamo" — mismo campo · contains · reclamo

Rama 3 — Spam:

Label: "Es spam" — mismo campo · contains · spam

Tip: Activá "Case sensitive = NO" en cada filtro. La IA a veces devuelve "Reclamo" con mayúscula.

Listo si: tu escenario tiene un router con 3 rutas y cada una con su filtro distinto.

Ejercicio 3 · 20 min

Cada rama hace algo distinto

Acá termina el flujo. Cada rama del router termina en una acción distinta:

Rama Consulta → Google Sheets · Add Row

Guardá: fecha, remitente, asunto, primeras 200 caracteres del cuerpo. Para que después un humano responda.

Rama Reclamo → Telegram · Send a Text Message

Mandá una alerta urgente con el asunto y el remitente. Esto es lo que NO podés dejar para mañana.

Rama Spam → Gmail · Add a label

Etiqueta el mail como "AutoSpam-IA" para revisarlo después. No lo borres en este ejercicio: queremos auditarlo primero por si la IA se equivoca.

Tocá para ver el plan de testeo

Para validar las 3 ramas en aula sin esperar mails reales, usá Run once y mandate 3 mails de prueba desde otra cuenta:

  1. Asunto: "Cuánto sale el envío a Mendoza?" → debería ir a Sheets
  2. Asunto: "Hace 2 semanas pedí y nunca llegó. Quiero plata." → debería ir a Telegram
  3. Asunto: "URGENTE!! HAZTE RICO YA!!! click aqui" → debería etiquetar como spam

Si una rama no se activa: revisá la respuesta exacta de la IA en el Run once. A veces devuelve "Es una consulta." y el filtro no encuentra la palabra exacta. Solución: ajustá el system prompt para que devuelva SOLO una palabra.

Listo si: los 3 mails de prueba terminaron cada uno en su destino correcto.

Nota Docente — Solo para el profesor

Esta práctica es la culminación del curso. Si un alumno no llega a terminar las 3 ramas, prioridad: que al menos tenga la IA clasificando y 1 rama con su acción. Es preferible 1 rama funcional que 3 a medio terminar. Acompañá especialmente la creación de la API Key de OpenAI: muchos se trancan ahí porque no tienen tarjeta cargada en plataforma OpenAI. Tener saldo mínimo (USD 5) cubre miles de tests.
