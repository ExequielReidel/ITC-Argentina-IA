Desarrollo teórico · 25 min

¿Qué es una API?

API significa "Application Programming Interface". Suena difícil. Te lo cuento como si fueras un cliente en un restaurante y todo va a tener sentido.

La analogía del restaurante

Imaginate que entrás a una pizzería. Vos sos tu negocio. La cocina es el sistema externo (Google, OpenAI, una empresa de pagos). El mozo es la API.

  • 1. Vos pedís al mozo: "Una pizza muzzarella, sin aceitunas, para 4". → Esto es tu request (pedido).
  • 2. El mozo va a la cocina, pasa el pedido, y vuelve con tu pizza. → Esto es la response (respuesta).
  • 3. Vos no entrás a la cocina. No sabés quién la cocinó ni cómo. Solo recibís el resultado.
  • 4. La carta del menú dice qué podés pedir. → Esto es la documentación API.

Una API es exactamente eso: un "mozo digital" que recibe tu pedido (request) y te trae el resultado (response). Vos no necesitás saber cómo funciona el sistema por dentro. Solo seguir las reglas del menú.

Las 4 cosas básicas de cualquier pedido a una API

URL (la dirección)

A qué "restaurante" estás yendo. Ej: https://dolarapi.com/v1/dolares/oficial

Método (qué querés hacer)

GET = pedir información. POST = enviar datos. PUT/DELETE = actualizar/borrar.

Headers (autenticación)

Tu "DNI digital". Algunos restaurantes piden reserva. Ej: API Key, Bearer Token.

Body (el pedido detallado)

El "qué querés exactamente". Solo va en POST. Ej: el texto que querés que ChatGPT te traduzca.

¿Y qué es JSON?

JSON es el formato en que se escriben las respuestas. Es una manera ordenada de listar información. Si pediste "los datos del cliente", la respuesta JSON sería:

{
  "nombre": "Vanesa Pérez",
  "email": "vanesa@email.com",
  "edad": 35,
  "ciudad": "Trelew",
  "activo": true
}

¿Te suena familiar? Es como un Excel pero en formato texto. Cada par "clave": "valor" es una columna y un dato. Make convierte ese JSON en variables que vos podés usar en los siguientes módulos.

JSON anidado

A veces JSON tiene "cajas adentro de cajas". Por ejemplo, si pedís el clima:

{
  "ciudad": "Buenos Aires",
  "clima": {
    "temperatura": 22.5,
    "descripcion": "parcialmente nublado",
    "humedad": 68
  }
}

Para acceder a "temperatura" desde Make, escribís {{1.clima.temperatura}}. El punto es como decir "adentro de la caja clima, agarrá el dato temperatura".

¿Cómo se lee la documentación de una API?

Toda API tiene una "documentación" pública (la "carta del menú"). Te indica:

  • Qué endpoints (URLs) están disponibles
  • Qué método usar en cada uno (GET / POST)
  • Qué parámetros aceptan
  • Cómo viene la respuesta JSON
  • Cuántas veces por minuto/hora podés llamarla (rate limit)

Buenas APIs argentinas gratuitas para practicar: dolarapi.com (cotización dólar), open-meteo.com (clima sin clave), holiday API (feriados).

Práctica guiada · 35 min

Caso: Mariano, vivero "Verde y Más" en Mar del Plata

Mariano vende plantas de exterior. Todos los días publica una recomendación de cuidado en Instagram según el clima. Hasta ahora lo hacía a mano. Vamos a automatizarlo: cada mañana a las 7 AM, Make consulta el clima, le pregunta a ChatGPT qué planta recomendar para ese clima y le guarda la sugerencia en Sheets para que Mariano publique.

1

Crear el escenario base

  • Crea un nuevo escenario y nombralo "Recomendación diaria de plantas".
  • Como trigger, usá "Schedule" (programado) → cada día a las 7:00 AM hora Argentina.
2

API #1: consultar el clima de MDP

  • Agregá módulo HTTP → "Make a request".
  • URL: https://api.open-meteo.com/v1/forecast?latitude=-38.0&longitude=-57.55&current=temperature_2m,weather_code&timezone=America/Argentina/Buenos_Aires
  • Método: GET.
  • Activá "Parse response: Yes" (Make convierte el JSON en variables).
  • Hacé clic en Run once y mirá la respuesta. Vas a ver datos como temperatura actual y código del clima.
Make te muestra todos los datos disponibles. Vas a poder usar {{2.current.temperature_2m}} en los próximos módulos.
3

API #2: pedirle a ChatGPT la recomendación

  • Agregá módulo OpenAI (ChatGPT) → "Create a Completion".
  • Te va a pedir API Key. (Si todavía no tenés, en la próxima clase la sacamos juntos. Por ahora te la doy de demo.)
  • En "Model": gpt-4o-mini (es económico).
  • En "Messages" → contenido del mensaje user:

Sos un experto en jardinería de Mar del Plata. La temperatura de hoy es {{2.current.temperature_2m}}°C.

Recomendá UNA planta de exterior ideal para hoy y dame:
1) Nombre
2) Por qué es ideal con este clima (1 frase)
3) Un consejo de cuidado para el día (1 frase)

Tono argentino cercano. Máximo 80 palabras total.

4

Guardar la sugerencia en Google Sheets

  • Antes, creá una planilla nueva con columnas: Fecha, Temperatura, Recomendación.
  • Agregá módulo Google Sheets → "Add a Row".
  • Mapea las variables: Fecha = {{now}}, Temperatura = {{2.current.temperature_2m}}, Recomendación = {{3.choices[].message.content}}.
  • Probá el escenario completo con "Run once".
5

Notificación a Mariano por mail

  • Agregá módulo Gmail → "Send an Email".
  • To: tu mail. Subject: 🌱 Recomendación del día listada

Buen día!

Hoy en MDP: {{2.current.temperature_2m}}°C

Recomendación generada para Instagram:

{{3.choices[].message.content}}

Subila a la planilla y publicá cuando puedas.

Resultado: todas las mañanas a las 7 AM, Mariano abre el celular y tiene la recomendación lista. Solo tiene que copiarla a Instagram. Antes le llevaba 30 minutos pensar y armar el post. Ahora 2.

Plantilla universal: cualquier flujo con APIs

Esta es la lógica que vas a repetir todas las veces que conectes APIs externas:

  1. Trigger (qué arranca el flujo)
  2. API GET (consultar datos externos: clima, dólar, stock)
  3. API POST con IA (procesar con ChatGPT, Claude, etc.)
  4. Acción (guardar en Sheets, enviar mail, mandar WhatsApp)
  5. Notificación (avisar a vos o tu equipo)

Ejercicio autónomo · 15 min

Tu primer flujo con API

Pensá una API útil para tu negocio. Algunas ideas según rubro:

  • Negocios afectados por el dólar: consultar dolarapi.com cada mañana y avisar el valor.
  • Negocios estacionales: consultar el clima y planificar promociones (heladería, lavadero, vivero).
  • Negocios con feriados: consultar API de feriados y ajustar horarios.
  1. Elegí una API gratuita relevante.
  2. Armá el escenario: trigger programado → API → acción.
  3. Probalo. Verificá que los datos se mapeen bien.
  4. Activalo y dejalo corriendo.

Desafío extra: agregá un módulo de IA al medio del flujo para "interpretar" los datos crudos y devolver una recomendación humana lista para usar.
